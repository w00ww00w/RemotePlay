# RemotePlay

Трансляция экрана компьютера на телевизор через браузер в одной локальной сети.

## Запуск

```powershell
npm start
```

1. На компьютере откройте адрес `http://localhost:8080` и нажмите «Начать трансляцию».
2. Нажмите «Выбрать телевизор» для AirPlay/Remote Playback либо откройте на телевизоре короткую ссылку `/tv`, которую сервер показал в терминале.
3. Разрешите Node.js доступ через брандмауэр только для частных сетей, если Windows спросит.

Передача работает, пока открыт сервер и активна трансляция. Звук рабочего стола зависит от браузера и операционной системы.

## Трансляция с другого компьютера

На основном компьютере оставьте `npm start` запущенным. Скопируйте папку RemotePlay на второй компьютер и выполните там:

```powershell
npm run sender -- http://192.168.1.10:8080/tv
```

Подставьте ссылку `/tv` из терминала основного сервера. Затем откройте адрес `localhost`, который покажет запускатор, и начните трансляцию.

Готовый `RemotePlaySender` из папки `release` делает то же самое без установки Node.js. Запустите файл и вставьте ссылку `/tv` основного сервера.

## Автономный сервер на Mac с M-чипом

Распакуйте `RemotePlayServer-macos-arm64.tar.gz` и запустите `RemotePlay Server.app`. Приложение само откроет страницу захвата экрана и покажет короткий адрес `/tv` для телевизора. Node.js не требуется.

## Сборка автономного сервера

Требуется .NET 9 SDK.

```powershell
dotnet publish server-app/RemotePlayServer.csproj -c Release -r win-x64 --self-contained -o release/windows
dotnet publish server-app/RemotePlayServer.csproj -c Release -r osx-arm64 --self-contained -o release/macos
```

Готовые сборки намеренно не хранятся в Git: каталог `release` создаётся локально.
